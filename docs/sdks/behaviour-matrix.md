# SDK behaviour matrix

Which protocol scenario each SDK passes. The scenarios are those of [`conformance/protocol`](../../conformance/protocol/README.md): `scenarios.json`, `versioning-scenarios.json` and `experiment-scenarios.json`, and for a browser client `page-scenarios.json`. Each SDK's section is generated by its own test suite from the scenarios its protocol runner executes, with no skip list, and that suite fails when the committed section differs from what it would generate, so this page can neither run ahead of the runners nor fall behind them.

The Go SDK evaluates locally with a server key, so its section holds the server-mode scenarios. SDKs that also evaluate remotely with a client key run the client-mode scenarios too: the JavaScript SDK's server mode plays the server-mode scenarios and its browser client the client-mode ones.
